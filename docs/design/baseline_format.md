# Baseline format

The baseline is the approved state of every monitored file (FR-02). It is stored as
`baseline.json` in the agent's state directory, which in the lab is the `agent-state` volume
that no other container can mount (SR-02).

```json
{
  "version": 1,
  "created_at": "2026-11-04T18:21:44.912Z",
  "created_by": "demo-admin",
  "reason": "initial baseline",
  "algorithm": "HMAC-SHA256",
  "entries": {
    "/data/models/gpt2-124m.safetensors": {
      "sha256": "248dfc39...",
      "size": 548105171,
      "mode": "0644",
      "owner": "1000:1000",
      "mtime": "2026-10-28T09:12:03.114Z",
      "asset": "model"
    }
  },
  "signature": "5f0c1e..."
}
```

| Field | Meaning |
|---|---|
| `sha256` | Content digest, computed in 4 MB chunks (FR-04); the only field that decides "modified" |
| `size` | Bytes |
| `mode` | Permission bits in octal; a change is reported as `meta` / MEDIUM (T-07) |
| `owner` | `uid:gid`; empty on Windows |
| `mtime` | Informational only. `touch -r` can fake it (T-08), so decisions never use it |
| `asset` | `model`, `config`, `vectordb` or `dataset`; selects the alert severity |
| `created_by`, `reason` | Who renewed the baseline and why (FR-03) |

## Signature (SR-01)

`signature = HMAC-SHA256(key, JSON(baseline with signature = ""))`. Go's `encoding/json`
sorts map keys, so the encoding is deterministic. The agent verifies the signature

* on start-up: a bad signature is logged as CRITICAL and the agent refuses to run;
* every 2 s when the file's mtime changes, and before every full scan: a forged file is
  logged as CRITICAL and the last trusted baseline stays in memory.

The key is 32 random bytes generated by `fimagent init` (`hmac.key`, mode 0600), or comes from
`FIM_HMAC_KEY` / `FIM_HMAC_KEY_FILE` (Docker secret) so it never has to sit in the repo (SR-08).

## Renewal

Only the CLI writes a baseline: `fimagent init`, `fimagent rebaseline -reason ...` and
`fimagent maintenance off`. Each writes a `baseline` record to the log with the operator name.
The file is written to a temporary file and renamed, so a crash never leaves half a baseline.
